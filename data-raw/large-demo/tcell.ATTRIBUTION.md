# Attribution — pan-cancer T-cell demo

`run-demo.R --data=tcell` builds a Viewer data set from the public pan-cancer T-cell atlas. **No data file is part of this repository or of the installed package**: the script downloads the sources into the user cache and builds the `.crb`, the `.h5` expression file and the `.immune.qs2` repertoire file there.

Only these members are used: the 70 `data/expression/CD4|CD8/byDataset/*.sce.rds` objects, `data/metaInfo/panC.freq.all.meta.tb.rds`, `data/metaInfo/CD8_Tex.dpt_pseudotime.txt.gz`, `data/metaInfo/TableS1.clinicalInfo.P316.txt` and `data/tcr/byCell/tcr.zhangLab.comb.flt.rds`. The 70 expression objects are the CD4 and CD8 T cells of the 35 data sets the atlas integrates, which include data sets published by other groups (listed in `dataset` and `data_source` of the cell table, and in the paper).

## What the Viewer data set contains, and what was changed

The licence asks for the changes to be stated:

- **Cells and patients.** All 397,810 T cells of the atlas's cell table, 316 patients, 21 cancer types, 41 meta-clusters, as published.
- **Expression.** The authors' `norm_exprs` matrix of each data set, joined on the union of the genes of the 70 files (a gene a data set does not carry is zero there). The data sets of the authors' laboratory are keyed by Ensembl identifier and are renamed to the symbol of their `display.name`; when several identifiers share a symbol the one detected in most cells is kept. Only gene symbols that at least 20 cells express are kept (36,625 genes); Ensembl identifiers without symbol and numeric names are dropped. It is log-normalised for 10x data and log2(TPM + 1) for Smart-seq2 data, as the authors provide it; the scales of the two technologies differ. Raw counts are not in every file and are not used.
- **Embedding.** The atlas publishes embeddings only for mini-clusters, not for single cells. The `harmony_umap` projection is **computed here**: variable genes chosen in each data set (Seurat `mean.var.plot` rule) and ranked by how many data sets pick them (top 2,000), each gene centred and scaled within its data set (clipped at 10), 30 principal components, Harmony across the 35 data sets, UMAP. It is not a figure of the paper.
- **TCR.** The TCR table covers 168,901 cells of 86 patients. Per cell the first listed α and β chain are used (the second only when the first is absent, or `-` in 10x rows). `CTaa` is the CDR3 amino acid pair; `CTgene` the V and J genes; `CTnt` is the authors' recombinant identifier (V gene, junction nucleotides, J gene) of the two chains with its fields joined by `:`, because the table has no CDR3 nucleotide column. The identifier reads `V_junction_J` for Smart-seq2 cells and `V|D|J|C|junction` for 10x cells; the D and C genes of the 10x identifier are left out, so both give `V:junction:J`. A repertoire sample is a patient and a tissue site (`loc`: T, N, P, L as published), written `patient (T)`.
- **Trajectory.** The CD8 continuum (naive, memory, effector memory, tissue-resident memory, exhausted) with the authors' diffusion pseudotime (`CD8_Tex.dpt_pseudotime.txt.gz`). The pseudotime belongs to **mini-clusters**; every CD8 cell of a mini-cluster has its value (159,858 cells), which is the cell table column `cd8_dpt`. The published values crowd between 0.85 and 0.88 for half of the cells, so the trajectory's `pseudotime` is their rank scaled to (0, 1], which keeps the order. `state` is the meta-cluster. The line drawn through the states joins their median positions in pseudotime order; it is not a fitted tree. The coordinates are those of the computed UMAP above.
- **Clinical columns** (`gender`, `age`, `clinical_stage`, `cancer_name`) come from the paper's Table S1 and are joined on the patient identifier.
